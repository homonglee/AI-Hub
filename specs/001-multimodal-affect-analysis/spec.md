# Feature Specification: 대면 1:1 대화 멀티모달 감정 분석

**Feature Branch**: `001-multimodal-affect-analysis`

**Created**: 2026-11-25

**Status**: Draft

**Input**: User description: "affective 분석기술을 활용하여 오프라인 1:1 대면 대화나 인터뷰에서 표정, 시선, 음성을 실시간 분석하는 멀티모달 AI 시스템"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 실시간 단일 모달리티 모니터링 (Priority: P1)

진행자(인터뷰어·상담사)가 세션을 시작하면 두 참여자 각각의 표정 지표(valence/arousal, 주요 Action Unit)와 음성 운율(피치, 에너지, 발화 속도)이 대시보드에 1초 단위로 갱신된다.

**Why this priority**: 캡처·동기화·추론·시각화 전 구간이 처음으로 연결되는 최소 단위이며, 이후 모든 기능의 기반이다.

**Independent Test**: 카메라 2대와 마이크 2개를 연결하고 5분 세션을 진행해 두 화자의 지표가 실시간으로 표시되고, 지표가 실제 표정·목소리 변화(미소, 큰 목소리)에 반응하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 두 참여자의 동의가 기록된 상태, **When** 진행자가 세션을 시작하면, **Then** 3초 이내에 두 화자의 표정·운율 지표가 표시되기 시작한다.
2. **Given** 세션 진행 중, **When** 참여자 A가 미소를 지으면, **Then** A의 valence와 AU12 값이 1초 이내에 상승한다.
3. **Given** 동의가 기록되지 않은 상태, **When** 진행자가 세션 시작을 누르면, **Then** 시스템은 시작을 거부하고 동의 절차로 안내한다.

---

### User Story 2 - 시선 및 대화 역학 지표 (Priority: P2)

진행자는 상호 응시 비율, 시선 회피, 발화 점유율, 턴 전환 지연, 끼어들기 횟수를 실시간으로 확인한다.

**Why this priority**: 1:1 대화 분석의 차별화 가치가 개인 감정보다 두 사람 사이의 상호작용에 있기 때문이다.

**Independent Test**: 대본에 따라 눈맞춤·회피·끼어들기를 연출한 세션을 녹화 재생 모드로 입력해 지표가 연출 구간과 일치하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 세션 진행 중, **When** 두 사람이 서로의 얼굴을 응시하면, **Then** 상호 응시 상태가 표시된다.
2. **Given** 세션 진행 중, **When** B가 A의 발화 도중 말을 시작하면, **Then** 끼어들기 카운트가 증가한다.

---

### User Story 3 - 멀티모달 융합과 개인 기준선 (Priority: P3)

세션 초반 기준선 구간을 측정한 뒤, 표정·음성·텍스트를 융합한 통합 정서 지표를 개인 기준선 대비 변화량으로 표시한다.

**Why this priority**: 단일 모달리티의 오류를 줄이고 개인차를 보정하지만, US1·US2가 안정된 이후에 의미가 있다.

**Independent Test**: 기준선 구간 이후 감정 자극 구간이 포함된 녹화 세션에서, 융합 지표가 단일 모달리티 지표보다 사람 라벨과 더 높은 상관을 보이는지 측정한다.

**Acceptance Scenarios**:

1. **Given** 세션 시작 후 기준선 구간이 끝난 상태, **When** 지표가 표시될 때, **Then** 절대값과 기준선 대비 변화량이 함께 표시된다.
2. **Given** 한 모달리티(예: 얼굴 가림)가 일시적으로 결측되면, **When** 융합이 계산될 때, **Then** 남은 모달리티로 계산하고 신뢰도를 낮춰 표시한다.

---

### User Story 4 - 세션 사후 리포트 (Priority: P4)

세션 종료 후 진행자는 타임라인, 주요 변화 구간, 대화 역학 요약, 전사 텍스트가 포함된 리포트를 확인하고 내보낸다.

**Why this priority**: 실시간 화면만으로는 놓치는 패턴을 검토할 수 있게 하지만, 실시간 기능이 먼저 필요하다.

**Independent Test**: 저장된 특징값 시계열로부터 리포트를 생성해, 타임라인의 특정 시점을 클릭하면 해당 시점의 지표와 전사가 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 종료된 세션, **When** 진행자가 리포트를 요청하면, **Then** 30초 이내에 리포트가 생성된다.
2. **Given** 보유기간이 지난 세션, **When** 파기 작업이 실행되면, **Then** 해당 세션의 특징값과 리포트가 모두 삭제된다.

### Edge Cases

- 얼굴이 프레임 밖으로 나가거나 손·마스크로 가려질 때: 해당 지표를 결측으로 표시하고 보간하지 않는다.
- 두 사람이 동시에 말할 때: 화자별 마이크 채널로 분리하되, 크로스토크가 큰 구간은 신뢰도를 낮춘다.
- 조명이 급변하거나 역광일 때: 얼굴 검출 품질 점수를 표시하고 임계값 이하면 경고한다.
- 안경 반사로 시선 추정이 불안정할 때: 시선 지표의 신뢰도를 낮춘다.
- 장치가 세션 중 분리될 때: 세션은 유지하고 해당 모달리티를 결측 처리하며 진행자에게 알린다.
- 참여자가 세션 중 동의를 철회할 때: 즉시 분석을 중단하고 해당 참여자 데이터를 파기한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 세션 시작 전 모든 참여자의 동의(항목, 보유기간 포함)를 기록해야 한다.
- **FR-002**: 시스템은 화자별 영상 1채널과 음성 1채널을 동시에 수집하고, 공통 시계로 타임스탬프를 붙여야 한다.
- **FR-003**: 시스템은 화자별 표정 지표(valence, arousal, 주요 AU 강도)를 산출해야 한다.
- **FR-004**: 시스템은 화자별 시선 방향과 상대 얼굴 응시 여부, 깜빡임을 산출해야 한다.
- **FR-005**: 시스템은 화자별 발화 구간, 운율 특징, 음성 감정(valence/arousal)을 산출해야 한다.
- **FR-006**: 시스템은 한국어 발화를 전사하고 텍스트 감성 점수를 산출해야 한다.
- **FR-007**: 시스템은 대화 역학 지표(발화 점유율, 턴 전환 지연, 끼어들기, 상호 응시 비율)를 산출해야 한다.
- **FR-008**: 시스템은 모든 지표에 신뢰도 값을 붙이고, 결측을 명시적으로 표현해야 한다.
- **FR-009**: 시스템은 개인 기준선 구간을 설정하고 기준선 대비 변화량을 산출해야 한다.
- **FR-010**: 시스템은 실시간 대시보드에 지표를 1초 이하 주기로 갱신해야 한다.
- **FR-011**: 시스템은 기본 설정에서 원본 영상·음성을 저장하지 않고 특징값만 저장해야 한다.
- **FR-012**: 시스템은 녹화 파일을 입력으로 받는 오프라인 재생 모드를 지원해야 한다.
- **FR-013**: 시스템은 세션 사후 리포트를 생성하고 PDF로 내보낼 수 있어야 한다.
- **FR-014**: 시스템은 보유기간이 지난 데이터와 동의 철회된 데이터를 자동 파기해야 한다.
- **FR-015**: 시스템은 사람에 대한 판정성 라벨(합격, 거짓말 등)을 출력하지 않아야 한다.
- **FR-016**: 시스템은 [NEEDS CLARIFICATION: 주 사용 목적 — 연구, 상담, 채용 면접 보조 중 무엇인가? 채용이면 추가 규제 대응 필요]
- **FR-017**: 시스템은 [NEEDS CLARIFICATION: 시선 정밀도 — RGB 추정(3~5°)으로 충분한가, 안경형 아이트래커 연동이 필요한가?]
- **FR-018**: 시스템은 [NEEDS CLARIFICATION: 배포 형태 — 고정형 인터뷰실 워크스테이션인가, 이동형(Jetson) 키트인가?]

### Key Entities

- **Session**: 한 번의 대화. 시작·종료 시각, 진행자, 장소, 보유기간, 상태.
- **Participant**: 세션 내 화자(A/B). 역할, 할당된 카메라·마이크 채널, 기준선 통계.
- **Consent**: 참여자별 동의 기록. 동의 항목, 시각, 철회 여부.
- **FeatureFrame**: 특정 시점·화자·모달리티의 특징값과 신뢰도.
- **FusedState**: 시간 윈도우별 화자의 통합 정서 지표와 기준선 대비 변화량.
- **InteractionMetric**: 두 화자 간 대화 역학 지표의 시간 윈도우별 값.
- **TranscriptSegment**: 발화 구간의 화자, 시작·끝, 텍스트, 텍스트 감성.
- **Report**: 세션 요약 리포트와 내보내기 파일.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 진행자는 장비 연결 후 2분 이내에 세션을 시작할 수 있다.
- **SC-002**: 표정 지표는 실제 표정 변화 후 1초 이내에 대시보드에 반영된다(p95).
- **SC-003**: 모달리티 간 타임스탬프 정렬 오차는 20ms 이내다.
- **SC-004**: 60분 연속 세션 동안 프레임 드롭률 1% 이하로 동작한다.
- **SC-005**: 한국어 전사 문자 오류율(CER)이 대면 대화 테스트셋에서 10% 이하다.
- **SC-006**: 융합 지표와 사람 라벨(valence) 간 상관계수(CCC)가 단일 최고 모달리티보다 높다.
- **SC-007**: 성별·연령 그룹 간 표정 valence 오차 차이가 사전에 정한 허용치 이내다.
- **SC-008**: 기본 설정 세션 종료 후 디스크에 원본 미디어 파일이 0건이다.

## Assumptions

- 2인 대면, 착석 상태, 실내 조명이 통제된 환경을 가정한다.
- 화자별 핀마이크를 사용해 음성 채널이 분리된다고 가정한다.
- 단일 GPU 워크스테이션(VRAM 12GB 이상)에서 2인 동시 처리한다.
- 진행자 1인이 대시보드를 보는 단일 사용자 앱으로 시작하며, 다중 사용자 계정 관리는 v1 범위 밖이다.
- 한국어 감정 데이터(AI-Hub 공개 데이터 등)를 파인튜닝·검증에 사용할 수 있다.
